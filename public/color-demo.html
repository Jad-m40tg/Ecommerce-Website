Color System

How the product-page swatches get their colors, and every color the system recognizes.

How it works. In the admin product editor you type colors as names, e.g. Charcoal, Sage, Wood. The product page looks each name up in the COLOR_HEX map (utils.js) to pick the swatch fill. Matching is case-insensitive and ignores leading/trailing spaces. If a name isn't in the map, the swatch falls back to #e8e0d3 (light beige) so it stays visible. The name you typed is what's saved with the order and shown next to "Color".
